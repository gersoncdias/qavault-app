# QA Vault

**Capture, organize e compartilhe evidências de testes.**

O QA Vault é um aplicativo desktop criado para profissionais de Quality Assurance registrarem evidências com mais rapidez e organização.

Capture screenshots, grave vídeos, proteja informações sensíveis, organize os arquivos em pastas e gere links para compartilhar em bugs, tarefas, relatórios e canais de comunicação.

## Principais recursos

- Captura de screenshots pelo aplicativo desktop
- Gravação de vídeos de evidência
- Preview antes do envio
- Corte e melhoria de imagens
- Pixelização de informações sensíveis
- Organização de evidências em pastas
- Upload manual de imagens e vídeos
- Geração de links para compartilhamento
- Histórico de evidências recentes
- Integração com Google Drive
- Aplicativo disponível para Windows e Linux
- Página web para upload de arquivos e importação de evidências geradas em testes mobile

## Como funciona

1. Abra o QA Vault.
2. Faça login com sua conta Google.
3. Conecte uma conta do Google Drive para armazenar suas evidências.
4. Capture uma imagem, grave um vídeo ou envie um arquivo.
5. Revise e edite a evidência antes de salvar.
6. Organize o conteúdo em uma pasta.
7. Gere e copie o link da evidência.
8. Compartilhe no Jira, Azure DevOps, Slack, Microsoft Teams ou em outra ferramenta.

## Reportar um problema

Encontrou um erro ou comportamento inesperado?

[Abra uma issue](https://github.com/gersoncdias/qavault-app/issues/new) informando:

- versão do QA Vault;
- sistema operacional;
- comportamento observado;
- comportamento esperado;
- passos para reprodução;
- prints ou vídeos, quando possível.

Não publique tokens, senhas, dados pessoais, evidências confidenciais ou informações internas da sua empresa.

## Status do projeto

O QA Vault está em evolução contínua. Entre os próximos objetivos estão:

- integração com Playwright e Cypress;
- upload automático de evidências;
- captura de requests, responses e erros de console;
- sincronização de eventos com a linha do tempo dos vídeos;
- relatórios e dashboards;
- melhorias de colaboração e organização;
- novas opções de armazenamento.
